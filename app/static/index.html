    Connect Immersive Translate

    Each teammate does this once in their browser extension.

    1. Open Immersive Translate's settings and go to Translation services (翻译服务).
    2. Choose OpenAI and switch on Custom API Key (自定义 API Key).
    3. Paste the API address (自定义 API 接口地址):
    4. Paste the team key as the API key:
      Any model name works. Glossa always uses the model chosen in Settings.
    5. Set OpenAI as your translation service and open any foreign-language page.
    Prefer the custom API option?

    In Immersive Translate, turn on Beta features under Developer settings, then add a Custom API (自定义 API) service with this address:

    This route caches paragraph by paragraph, so memory works even when two pages share only a few sentences.
